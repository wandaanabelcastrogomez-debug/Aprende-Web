# Aprende Web

App para aprender HTML, CSS y JavaScript con lecciones cortas, editor y vista previa en vivo.

- 11 lecciones (HTML, CSS, JavaScript y un proyecto final)
- Zona libre para practicar
- Consola con errores en español sencillo
- Guarda tu progreso en el dispositivo
- Funciona en GitHub Pages y se puede convertir en app Android

Abre `index.html` con Live Server en VS Code para probarla.
